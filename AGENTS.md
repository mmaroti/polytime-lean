# Markdown

- Always do a minimal amount of edits in the text with minimal amount of addition.
- Always fix typos and correct grammar when you notice them.

# Lean style

- Name every Lean section and close it with a matching named `end`; avoid bare `end` commands where possible.
- Make names traceable: use explicit names and declarations whenever possible, including for universe levels and implicit parameters.
- Add Lean definitions and theorems only when needed by concrete examples; avoid speculative additions.
- Try to avoid introducing new Lean structures, keep their number to the absolute minimum. Always try to reuse Lean structures from Mathlib.
